# Опциональные зависимости: движок Kokoro-ru (пресетные встроенные голоса).
# Ставится отдельно от основного набора:
#
#   ./venv/bin/pip install -r requirements-kokoro.txt
#
# Без --no-deps, в отличие от requirements-qwen.txt: конфликтов версий здесь нет.
# `kokoro` требует torch, transformers и huggingface_hub без ограничений версий, то
# есть ровно те пакеты, на которых проверен проект. Установка «только пакета»
# (--no-deps) заставила бы перечислить руками всё дерево `phonemizer` (joblib,
# segments, typing-utils, attrs, dlinfo) — такая копия зависимостей разошлась бы
# с настоящей при первом же обновлении.
#
# Плата за обычную установку — `misaki[en]`, английский G2P для восьми языков
# Kokoro: в проекте он не используется, русская фонетика живёт в `ru_g2p.py` из
# репозитория модели (см. engines/kokoro_engine.py). Поэтому набор и вынесен из
# requirements.txt: это опция, а не рабочий минимум проекта.
#
# Веса движка (вместе с `ru_g2p.py` и пересобранным под ударения `espeak-data/`)
# скачиваются вкладкой «Модели» — см. docs/install.md. Пока их нет, движок не
# поднимается, но голоса на Kokoro не ломают диалог: паспорт движка разрешает
# откат на F5 (см. docs/synthesis.md).
kokoro==0.9.4    # KModel: инференс 82M-модели, 24 кГц (см. engines/kokoro_engine.py)
misaki==0.9.4    # ради misaki.espeak.EspeakG2P — его зовёт ru_g2p.py, выставляя espeak-ng

# Ожидаемые ответы

Gold-ответы лежат внутри самих кейсов — в поле `expected` файла
`dataset.v1.jsonl`. Отдельного дубликата здесь нет намеренно: две копии одной
разметки однажды разошлись бы, и benchmark мерил бы не тот корпус.

| Файл | Назначение |
|---|---|
| `analyzer.response.schema.json` | схема ответа модели (идёт в Ollama `format`) |
| `summary.json` | счётчики по категориям и список кейсов, требующих проверки человеком |

Проверка соответствия gold исходному тексту — в `tools/build_llm_dataset.py --check`
и в тестах `tests/test_llm_benchmark_dataset.py`.

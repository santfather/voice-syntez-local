# Инструкция для ИИ-агента: расширение фраз для записи голоса

## Контекст

Текущий `RECORD_PHRASES` (5 фраз) хорошо покрывает шипящие, вопросы, восклицания и сложные
согласные, но не гарантирует явное присутствие буквы «ё» и не покрывает часть интонационных
регистров (радость, огорчение, ирония, строгий приказ). Это связано с уже обсуждённой задачей
восстановления «ё» в тексте: чем разнообразнее «ё» в самой референс-записи, тем надёжнее потом
работает синтез на словах с этой буквой — референс должен содержать то, что модель потом будет
воспроизводить.

Правило из уже действующей рекомендации по референсам не отменяется: **одна эмоция и ровный темп
на весь текст фразы**, разнообразие — между фразами, а не внутри одной. Ни одну из фраз ниже не
нужно начитывать «через силу» с разными интонациями внутри одного прохода.

## Отдельно — не добавлять в основной список

**Шёпот/тихая интимная речь как отдельная фраза не рекомендуется.** У проекта уже есть проверка
пола голоса по F0 (`audio_analysis.py`) — шёпот акустически не имеет чёткой основной частоты
(F0), запись почти наверняка провалит эту проверку или даст недостоверный результат. Если нужен
регистр «тихо, доверительно» — просить начитать спокойным, негромким, но полноценно озвученным
голосом, не переходя в настоящий шёпот; в список выше такая фраза не включена, чтобы не провоцировать
её на буквальный шёпот подписью.

**Фраза-максимум по плотности «ё» — отдельно, не как обычный референс:**
```javascript
const YO_STRESS_TEST_PHRASE = 'Ёж и ёлка стоят у забора, а рядом идёт актёр в жёлтом плаще: он несёт мёд и лёд, поёт песню и совсем не мёрзнет.';
```
Эта фраза искусственно перегружена буквой «ё» и годится как тестовый текст для проверки модуля
восстановления «ё» в панели «Что услышит модель» (см. предыдущую задачу с нормализацией текста),
но **не для записи основного референса голоса** — противоестественная плотность одного и того же
звука ломает ровный темп начитки, который важен для качества клонирования (см. правило «одна
эмоция и ровный темп» в разделе про референсы). Использовать только как тестовые данные, не
предлагать пользователю в UI записи голоса.

**Критерий готовности:** в UI записи голоса доступно 11 фраз вместо 5, среди них минимум четыре
новых с явным присутствием буквы «ё» в разных позициях (после согласной — «мёд», «идёт»; в
начале слова — не покрыто основным списком намеренно, только тестовой фразой) и минимум три
новых интонационных регистра (радость, огорчение/сочувствие, ирония), которых не было в исходных
пяти.

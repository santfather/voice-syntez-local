# Журнал фаз проекта

Короткая хронология: что и в каком порядке появилось в VOICE_SYNTEZ. Нужна, чтобы понимать,
откуда взялась подсистема и почему решение принято именно так. Подробности текущего поведения —
на профильных страницах [`docs/`](README.md), полные тексты — в истории git.

## Как читать журнал

- Все коммиты — в `git log`; у каждого в теле есть подробное описание, что и зачем сделано.
- До коммита с пометкой `cleaning` в корне репозитория лежали планы, спецификации и отчёты по
  фазам (например `updates.md`, `update_3.md`, `AUDIT.md`, `PHASE_2_SAM_SEBE_ZVUKOREZHISSER.md`).
  Они удалены, а их актуальное содержание перенесено в `docs/`. Достать любой файл целиком можно
  из истории:

```bash
git log --oneline --all -- update_3.md        # когда и как менялся файл
git show <commit>:update_3.md > /tmp/update_3.md
git log --diff-filter=D --name-only --pretty=format:'%h %s' -- '*.md' | head -40
```

## Что снято с эксплуатации

- Ручная активация venv и `run.sh` — работают, но основной способ запуска теперь
  `VOICE_SYNTEZ.command` (см. [`install.md`](install.md)).
- Один большой `README.md` как база знаний — заменён коротким README и набором страниц `docs/`
  (см. [`docs/README.md`](README.md)).

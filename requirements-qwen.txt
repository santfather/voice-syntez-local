# Опциональные зависимости: движок Qwen3-TTS 1.7B (Base) для клонирования голоса.
# Ставится отдельно от основного набора и только с --no-deps:
#
#   ./venv/bin/pip install --no-deps -r requirements-qwen.txt
#
# --no-deps здесь обязателен: qwen-tts 0.1.1 объявляет transformers==4.57.3, а
# весь проект проверен на transformers 5.17.0 (Whisper в transcribe_worker.py и
# coqui-tts). Обычная установка откатила бы пятую версию назад и сломала их.
# Совместимость с пятой версией держит шим в backend/engines/qwen_engine.py —
# тем же приёмом, что применён к coqui-tts (см. engines/xtts_engine.py).
#
# Остальные зависимости пакета (accelerate, einops, onnxruntime, librosa,
# torchaudio, soundfile) в окружении проекта уже есть: их тянут f5-tts, coqui-tts
# и librosa. Сам пакет ничего не объявляет про sox — он нужен только для
# экзотических форматов входа, а референсы проекта идут через ffmpeg.
#
# Без установленного пакета движок не поднимается и в логе будет ошибка с этой
# же командой; голоса на Qwen при этом не ломают диалог — паспорт движка
# разрешает откат на F5 (см. docs/synthesis.md).
qwen-tts==0.1.1
